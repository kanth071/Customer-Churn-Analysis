# 📊 Customer Churn Prediction Project

## 📌 Project Overview

This project focuses on building a **Machine Learning-based Customer Churn Prediction system**.  
The goal is to identify customers who are likely to leave a service (churn) based on their historical and behavioral data.

Churn prediction helps businesses improve customer retention by taking proactive actions.

---

## 🎯 Objective

- Predict whether a customer will churn or not
- Identify key factors influencing churn
- Help businesses reduce customer loss
- Build a classification model using machine learning

---

## 📂 Dataset

The dataset contains customer information such as:

- Customer demographics
- Account information
- Subscription details
- Usage behavior
- Churn status (Target variable)

Target column:
- `Churn` → Yes / No (converted to 1 / 0)
